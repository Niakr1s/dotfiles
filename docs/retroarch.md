# Installation

```
sudo zypper install retroarch
```

Then launch it and go to main menu > online updater and click on all `Update-*` buttons.
It's possible to install all bioses at once, but they are wery big (5GB+):

```
curl -fsSL https://raw.githubusercontent.com/Abdess/retrobios/main/install.sh | sh
```

Or you can copy BIOSes from [TopRoms Collection](https://github.com/cdahmedeh/TopRoms) (Currently I have them at `/data/hdd20/Games/ROMs/TopRoms Collection/BIOS - RetroArch/system`) and put them into `/home/nea/.config/retroarch/system`. It's size ~500MB, almost all ROMs intended to launch from RetroArch are working the same as full pack.
